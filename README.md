# AVIBOOM

Сайт агентства продвижения бизнеса на Авито.

## Редактирование

1. Открой `https://<your-site>/admin/`
2. Войди через GitHub
3. Редактируй файлы
4. Изменения автоматически деплоятся через GitHub Actions

## Структура

- `index.html` — главная
- `cases/` — кейсы (8 страниц)
- `niches/` — ниши (12 страниц)
- `locations/` — города (34 страницы)
- `blog/` — блог
- `legal/` — юридические документы
- `images/` — изображения
- `admin/` — Decap CMS админка

## Деплой

GitHub Actions автоматически деплоит сайт на GitHub Pages при push в `main`.
